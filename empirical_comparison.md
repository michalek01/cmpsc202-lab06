Comparing recursive, memoized and Bottum up

The comparison that is obvious in Figure 1 is that the recursive function grows increasily slower very fast as the amount of coins the algorithm has to go through increases. The recursive algortihm is like this because is repeatley solves overlapping subproblems. Memoization works very similar but instead of solving those problems again it keeps those results in a dictionary to save those results that the recursive function would be repeatly solving. The bottom up dynamic function uses a list called dp where dp[i] stores the minimum number of coins needed to make the amount. So if we have a list of [1,5,10,25], the algorithm for every amount from 1 through target it checks each coin and uses the previously remenbered value to find the least amount of coins needed. It basically builds a table of the best answer for each amount of the coins.
